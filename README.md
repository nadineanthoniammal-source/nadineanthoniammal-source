## Featured Projects

### [ESGLens AI: Agentic ESG Report Analyzer](https://github.com/nadineanthoniammal-source/esglens-ai)
LangGraph agent that extracts key ESG metrics from Indian BRSR report PDFs using RAG and verifies each value against its source page to reduce LLM hallucination. Includes cited RAG Q&A, a greenwashing detector, an E/S/G classifier, and multi-year comparison. Hand-verified 8 of 8 fields on Reliance's FY 2024-25 BRSR and deployed as a live Streamlit app.
**Tech:** Python, LangGraph, LangChain, ChromaDB, RAG, Groq, scikit-learn, FastAPI, Streamlit

### CARDIA-X: Multimodal AI & IoT Health Monitoring System
Cloud-independent healthcare system that combines vitals, motion, and privacy-preserving vision for real-time emergency detection. Uses an agentic workflow with a local LLM (Phi-4 Mini) and RAG to generate caregiver summaries and trigger emergency alerts.
**Tech:** FastAPI, Python, LLMs (RAG), MediaPipe, MoveNet, OpenCV, ESP32

### HackVerse AI: AI-Powered Hackathon Management Platform
AI-driven workflow automation for team registration, LLM-based scoring, shortlisting, QR attendance, and certificate generation, built on n8n Cloud with a React + Vite frontend.
**Tech:** n8n, Groq, React.js, Vite, REST APIs, Google Sheets

### Q-TwinAir: Hybrid Digital Twin for Aircraft Monitoring
Aircraft health monitoring with live ESP32 sensor data, Kalman filtering, and a 3D dashboard.
**Tech:** React, Three.js, FastAPI, ESP32, Kalman Filter

### Trip Smart: Mobile Travel Guide
